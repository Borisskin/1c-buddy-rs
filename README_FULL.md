# onec-buddy-mcp: подробное руководство

`onec-buddy-mcp` подключает Codex, Cursor и Claude Desktop к «1С:Напарнику» по протоколу MCP. Сервер работает локально через стандартный ввод-вывод, не открывает входящий порт и не предоставляет веб-интерфейс.

Готовая поставка поддерживает Windows x86-64. В архив входит исполняемый файл `onec-buddy-mcp.exe`, собранный для `x86_64-pc-windows-msvc` со статически подключённой средой выполнения MSVC.

## Быстрый старт

1. Скачайте `onec-buddy-mcp-windows-x86_64.zip` и распакуйте его в постоянный локальный каталог, например `C:\tools\onec-buddy-mcp`.
2. Задайте личный токен «1С:Напарника» как переменную пользователя Windows:

   ```powershell
   [Environment]::SetEnvironmentVariable(
       "ONEC_AI_TOKEN",
       "<ваш_токен>",
       "User"
   )
   ```

3. Добавьте сервер в `%USERPROFILE%\.codex\config.toml`:

   ```toml
   [mcp_servers.onec_buddy]
   command = 'C:\tools\onec-buddy-mcp\onec-buddy-mcp.exe'
   env_vars = ['ONEC_AI_TOKEN']
   ```

4. Полностью перезапустите Codex. В списке MCP-серверов должен появиться `onec_buddy` с восемью инструментами.

## Состав поставки

Архив `onec-buddy-mcp-windows-x86_64.zip` содержит ровно пять файлов:

| Файл | Назначение |
|---|---|
| `onec-buddy-mcp.exe` | MCP-сервер для Windows x86-64 |
| `README.md` | Краткое описание и быстрый старт |
| `README_FULL.md` | Это подробное руководство |
| `LICENSE` | Текст лицензии |
| `.env.example` | Справочник переменных окружения |

Рядом с архивом публикуется `SHA256SUMS.txt` с контрольными суммами исполняемого файла и архива. Проверьте архив до распаковки:

```powershell
(Get-FileHash -LiteralPath ".\onec-buddy-mcp-windows-x86_64.zip" -Algorithm SHA256).Hash.ToLowerInvariant()
Get-Content -LiteralPath ".\SHA256SUMS.txt"
```

Полученное значение должно совпасть со строкой для `onec-buddy-mcp-windows-x86_64.zip`.

## Установка

1. Создайте постоянный локальный каталог без ограничений на запуск программ, например `C:\tools\onec-buddy-mcp`.
2. Распакуйте в него все пять файлов. Для работы нужен `onec-buddy-mcp.exe`; остальные файлы сохраняют инструкции, пример настроек и условия лицензии.
3. Выберите ровно один источник токена и задайте его до запуска клиента MCP.
4. Укажите абсолютный путь к `onec-buddy-mcp.exe` в настройках клиента.
5. Полностью перезапустите клиент, чтобы он получил обновлённое окружение.

Аргументы и подкоманда запуска не нужны. Каждый клиент запускает отдельный процесс сервера.

## Источники токена

Сервер принимает ровно один источник личного токена:

- `ONEC_AI_TOKEN` — переменная окружения пользователя или системы Windows;
- `ONEC_AI_TOKEN_FILE` — абсолютный локальный путь к обычному файлу.

Одновременное задание двух источников или отсутствие обоих приводит к ошибке запуска. Учитывается окружение процесса: если клиент уже запущен, он не увидит новую переменную до полного перезапуска.

### Токен в переменной Windows

Переменная пользователя доступна программам текущего пользователя:

```powershell
[Environment]::SetEnvironmentVariable(
    "ONEC_AI_TOKEN",
    "<ваш_токен>",
    "User"
)
```

Системная переменная доступна всем пользователям. Для её задания запустите PowerShell с правами администратора и замените область `User` на `Machine`:

```powershell
[Environment]::SetEnvironmentVariable(
    "ONEC_AI_TOKEN",
    "<ваш_токен>",
    "Machine"
)
```

### Токен в файле

Вместо значения токена можно передать путь:

```powershell
[Environment]::SetEnvironmentVariable(
    "ONEC_AI_TOKEN_FILE",
    "C:\Secrets\onec-ai-token.txt",
    "User"
)
```

`ONEC_AI_TOKEN_FILE` должен указывать на обычный локальный файл по абсолютному пути. Каталоги, ссылки, другие точки повторной обработки Windows, UNC-пути и служебные имена Windows не принимаются. Токен должен быть в UTF-8, без пробелов и управляющих знаков по краям; допустим один завершающий перевод строки. Значение токена и файл ограничены 8 КиБ.

[`.env.example`](.env.example) перечисляет все переменные и значения по умолчанию, но сервер не загружает этот файл автоматически. Переименование файла в `.env` также ничего не меняет: переменные должен передать Windows или программа, которая запускает сервер.

Примеры подключения ниже используют `ONEC_AI_TOKEN` из окружения клиента.

## Подключение клиентов

### Codex

Codex хранит настройки MCP в `%USERPROFILE%\.codex\config.toml` или в `.codex\config.toml` доверенного проекта. Формат соответствует разделу [Model Context Protocol](https://learn.chatgpt.com/docs/extend/mcp.md) официального руководства Codex.

Пример с передачей `ONEC_AI_TOKEN` из локального окружения Codex:

```toml
[mcp_servers.onec_buddy]
command = 'c:\tools\onec-buddy-mcp.exe'
env_vars = ['ONEC_AI_TOKEN']
```

После сохранения настройки полностью перезапустите Codex и проверьте наличие восьми инструментов MCP.

### Cursor

Cursor читает настройки MCP из `%USERPROFILE%\.cursor\mcp.json`, если сервер должен быть доступен во всех проектах, или из `.cursor\mcp.json` в корне отдельного проекта. Поля `command` и `env`, а также оба места размещения файла описаны в официальном руководстве [Model Context Protocol (MCP)](https://cursor.com/docs/mcp).

Пример с передачей `ONEC_AI_TOKEN` из окружения Cursor:

```json
{
  "mcpServers": {
    "onec-buddy": {
      "type": "stdio",
      "command": "c:\\tools\\onec-buddy-mcp.exe",
      "env": {
        "ONEC_AI_TOKEN": "${env:ONEC_AI_TOKEN}"
      }
    }
  }
}
```

После сохранения настройки полностью завершите Cursor, запустите его снова, откройте настройки MCP и проверьте, что `onec-buddy` включён и публикует восемь инструментов.

### Claude Desktop

Claude Desktop читает `%APPDATA%\Claude\claude_desktop_config.json`. Абсолютный путь соответствует официальному руководству [Connect to local MCP servers](https://modelcontextprotocol.io/docs/develop/connect-local-servers). Пример не дублирует токен: сервер наследует `ONEC_AI_TOKEN` из окружения Claude Desktop.

Пример:

<!-- BEGIN CLAUDE CONFIG -->
```json
{
  "mcpServers": {
    "onec-buddy": {
      "command": "c:\\tools\\onec-buddy-mcp.exe"
    }
  }
}
```
<!-- END CLAUDE CONFIG -->

После задания переменной и сохранения настройки полностью завершите Claude Desktop, запустите его снова и проверьте `onec-buddy` в разделе подключённых инструментов.

Во всех показанных настройках используется `ONEC_AI_TOKEN` из окружения агента. Не добавляйте значение токена в файл настройки или `args`, не задавайте одновременно `ONEC_AI_TOKEN_FILE` и не указывайте адрес либо порт.

## Инструменты и схемы

`tools/list` публикует восемь основных имён:

| Инструмент | Назначение | Обязательные поля | Необязательные поля и значения по умолчанию |
|---|---|---|---|
| `ask_1c_ai` | Общий вопрос о платформе и разработке | `question: string` | `programming_language=""` (`""`, `BSL`, `SQL`, `JSON`, `HTTP`), `ssl_version=""`, `configuration=""` |
| `explain_1c_syntax` | Объяснение элемента языка или платформы | `syntax_element: string` | `context=""`, `ssl_version=""`, `configuration=""` |
| `check_1c_code` | Проверка синтаксиса или обзор кода | `code: string` | `check_type="syntax"` (`syntax`, `review`, `logic`, `performance`), `extended=false` |
| `modify_1c_code` | Изменение исходного кода по инструкции | `instruction: string` | `code=""` |
| `search_1c_documentation` | Поиск по документации платформы | `query: string` | `version="v8.5.1"` |
| `search_its` | Поиск по базе знаний ИТС | `query: string` | `ssl_version=""`, `configuration=""` |
| `fetch_its` | Чтение документа, каталога или корня ИТС | Нет | `id="root"` |
| `diff_1c_documentation_versions` | Сравнение документации двух версий | `version_a: string`, `version_b: string` | `query=""` |

Значения `ssl_version` и `configuration` по умолчанию берутся из `DEFAULT_SSL_VERSION` и `DEFAULT_1C_CONFIGURATION`; в таблице показаны исходные пустые значения. Необъявленные поля входного объекта игнорируются. Содержательная строка после удаления пробелов по краям должна содержать от `MCP_TOOL_INPUT_MIN_LENGTH` до `MCP_TOOL_INPUT_MAX_LENGTH` скалярных значений Юникода.

Четыре чувствительных к регистру прежних псевдонима принимаются только в `tools/call` и не публикуются:

| Псевдоним | Основное имя |
|---|---|
| `Search_1C_Documentation` | `search_1c_documentation` |
| `Search_ITS` | `search_its` |
| `Fetch_ITS` | `fetch_its` |
| `Diff_1C_Documentation_Versions` | `diff_1c_documentation_versions` |

## Режимы выполнения

- `direct` — режим по умолчанию. `check_1c_code` с `check_type="syntax"` и четыре поисковых инструмента используют закреплённые внутренние инструменты; остальные вызовы отправляются обычным сообщением.
- `standard` — все восемь инструментов отправляются обычным сообщением.
- Для `check_1c_code` значения `logic` и `performance` совместимо выполняются как `review`.
- Ошибка точного внутреннего инструмента в `direct` не вызывает скрытого перехода в `standard`.

## Необязательные настройки

| Переменная | По умолчанию | Допустимое значение |
|---|---:|---|
| `MCP_TOOL_INPUT_MIN_LENGTH` | `4` | от 1 до 100 000, не больше максимума |
| `MCP_TOOL_INPUT_MAX_LENGTH` | `100000` | от минимума до 100 000 |
| `MCP_TOOL_CALL_MODE` | `direct` | `direct` или `standard` |
| `ONEC_AI_UI_LANGUAGE` | `russian` | от 1 до 64 знаков Unicode |
| `ONEC_AI_PROGRAMMING_LANGUAGE` | пусто | от 0 до 64 знаков Unicode |
| `DEFAULT_SSL_VERSION` | пусто | от 0 до 256 знаков Unicode |
| `DEFAULT_1C_CONFIGURATION` | пусто | от 0 до 256 знаков Unicode |
| `MCP_MAX_CONCURRENT_CALLS` | `2` | `1` или `2` |
| `RUST_LOG` | `warn` | допустимый фильтр размером до 1 024 байт |

`ONEC_AI_BASE_URL` не поддерживается: адрес внешней службы нельзя менять через
окружение.

## Ограничения и передача данных

- каждый агент запускает собственный процесс;
- один вызов инструмента создаёт отдельную беседу;
- вопросы и пользовательский код передаются внешней службе `https://code.1c.ai`;
- автономного режима нет;
- входящий и исходящий кадр MCP ограничен 2 МиБ;
- одновременно выполняются не более одного или двух вызовов, ещё восемь могут ожидать;
- ожидание очереди ограничено 30 секундами, весь вызов — 300 секундами;
- токен, заголовок авторизации и пользовательский код не записываются в журнал;
- стандартный вывод нельзя использовать для технических сообщений.

Серверу требуется исходящее соединение с `https://code.1c.ai`. Вопросы, фрагменты пользовательского кода, параметры инструментов и контекст 1С передаются этой внешней службе для обработки. Автономного режима нет.

## Устранение неполадок

### Клиент не показывает сервер или инструменты

Проверьте абсолютный путь к `onec-buddy-mcp.exe`, имя раздела в настройках и полностью перезапустите клиент. Сервер не показывает окно и не открывает порт: клиент должен запускать его как дочерний процесс через стандартный ввод-вывод.

### Сервер сообщает об источнике токена

В окружении процесса должна быть ровно одна переменная: `ONEC_AI_TOKEN` или `ONEC_AI_TOKEN_FILE`. Удалите вторую переменную из настроек запуска либо окружения и перезапустите клиент. Файл `.env.example` сам по себе настройки не задаёт.

### Сервер не читает файл токена

Укажите абсолютный локальный путь к обычному файлу. Проверьте, что путь не сетевой, файл не является ссылкой, его размер не превышает 8 КиБ, а токен записан в UTF-8 без пробелов по краям.

### Вызов отклонён или завершился по времени

Проверьте обязательные поля по таблице схем и длину содержательных строк. Очередь вмещает восемь ожидающих вызовов; ожидание ограничено 30 секундами, а полное выполнение — 300 секундами.

### Нужен подробный журнал

Задайте допустимый фильтр `RUST_LOG`, например `info`, до запуска клиента. Технические сообщения идут в стандартный поток ошибок; стандартный вывод зарезервирован для сообщений MCP.
